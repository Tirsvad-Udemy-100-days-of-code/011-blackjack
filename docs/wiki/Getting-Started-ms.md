# Bermula

## Keperluan

Python 3.13 atau lebih baharu. Tiada kebergantungan semasa larian. Gunakan terminal yang menyokong UTF-8 dan emoji (contohnya Windows Terminal).

## Persediaan

```bash
python -m venv .venv
source .venv/bin/activate        # Windows PowerShell: .\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
```

## Jalankan

```bash
python -m blackjack
```

## Ujian

```bash
python -m unittest discover -s tests
```
